# .agents/

Cross-agent configuration for working **on** herdr-peers: `agents/`
(personas), `commands/` (thin `/dwp-*` delegators), `skills/` (vendored,
pinned skills — do not hand-edit; upgrade through `npx skills add …@<tag>`),
`docs/` (catalogs). `.claude` and `.cursor` are symlinks to this directory.
Start at the root [AGENTS.md](../AGENTS.md).
